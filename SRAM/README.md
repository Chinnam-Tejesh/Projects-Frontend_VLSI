# Project SRAM
SRAM stands for Static Random Access Memory, it is an semiconductor memory which by design offers high speeds (compared to DRAM).

SRAM with "Parallel Interface" is the core component which performs read and store of data.

SRAM is used in almost all applications in the modren world. And is core component where an Processor is needed.

SRAM is choosed over DRAM (its counterpart, Dynamic RAM) where performance is critical (compramising on power and area).
